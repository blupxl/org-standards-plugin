Acme design system

A stand-in for Acme's design-system site. The design team owns it; the design standards point here, and the standards server tells Claude its address.

Use it

Load the stylesheet, put acme-page on <body>, and use the component classes.

<link rel="stylesheet" href="http://localhost:5500/css/acme.css">
<!-- XYZ Public App: add the XYZ palette after it -->
<link rel="stylesheet" href="http://localhost:5500/css/xyz.css">
<!-- The public website: add the website theme (crimson, greys, white) instead -->
<link rel="stylesheet" href="http://localhost:5500/css/website.css">

Color tokens

--acme-primaryPrimary actions, links
--acme-surfacePage and card backgrounds
--acme-dangerErrors, destructive actions

XYZ Public App swaps in --xyz-primary, --xyz-surface and --xyz-danger through xyz.css; the components stay the same.

Components
